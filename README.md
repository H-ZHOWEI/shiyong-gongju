# 实用工具（shiyong-gongju）

一个单文件、带图形界面的 Windows 小工具合集。把几个常用但零散的功能整合到一个软件里，进度和结果都显示在主界面，后续还能继续加功能。

> 当前版本：**v1.4.3** · 许可证：仓库公开（源码与构建脚本一并开源，可自由学习、修改、分发）

---

## 功能一览

| 功能 | 说明 |
| --- | --- |
| 📁 文件夹图片 → Word | 选一个图片文件夹，按文件名顺序把所有图片导出到 Word（A4 / 每页 4 张 / 每张 7×11cm，无备注） |
| 📊 Excel 图片 → Word | 在界面上配置表格布局（备注列、图片起止列、图片放置方式：嵌入 / 浮动 / 自动），软件据此解析并导出 Word |
| 🔁 Word 批量替换 | 选一个 Word 文档文件夹，批量查找 / 替换文字，保留原格式，支持正则、备份、页眉页脚表格、子文件夹、可停止 |
| 🖨 批量打印（PDF） | 选一个或多个 PDF（或文件夹），逐个发送到系统打印机，调用系统自带 PDF 打印能力，不依赖第三方软件 |
| 🔗 PDF工具 | 跳转到 PDF24 在线工具合集（合并、分割、压缩、转换、加水印等） |

界面三栏布局：左侧功能列表、中间配置与功能介绍、右侧「成品」与「历史记录」（双击即可打开对应成品）。

## 内置「版本更新」

- 顶部常驻版本号 +「检查更新」按钮，**每次启动也会后台静默检查**。
- 发现新版本用**非模态横幅**提示（立即更新 / 跳过此版本 / 稍后再说），不打断使用。
- 下载支持多镜像、断点续传、分段并发，并做 **MZ 头 / 文件大小 / SHA256** 三重校验。
- 安装时原地替换正在运行的 exe（失败必还原、绝不退出），装完问「立即重启 / 稍后重启」。
- 清单地址支持多镜像并发取最高版本；默认不使用 jsDeliver（避免锁旧 commit 导致误报已是最新）。

## 运行方式

### 普通用户（推荐）—— 下载即用，无需安装任何东西

1. 点这里下载：**[⬇ 下载 实用工具.exe](https://github.com/H-ZHOWEI/shiyong-gongju/raw/main/dist/%E5%AE%9E%E7%94%A8%E5%B7%A5%E5%85%B7.exe)**
   （也可以在仓库里点开 `dist/实用工具.exe`，再点右上角的「Download raw file」图标下载。）
2. 把下载到的 `实用工具.exe` 放到任意文件夹（例如 `D:\实用工具\`），**双击就能打开**。
3. 不需要安装 Python、不需要安装任何运行库、不需要管理员权限。

> 说明：这是 PyInstaller 打好的**单文件独立 exe**，Python 解释器和全部依赖（Pillow / python-docx / openpyxl）都已经打包在里面，所以体积约 35MB，属于正常大小。

第一次打开如果 Windows 弹出「已保护你的电脑」蓝色提示，是因为这个 exe 没有买数字签名证书，属于正常现象：点「更多信息」→「仍要运行」即可。程序完全离线运行，不联网上传任何文件（只有你主动点「检查更新」时才会访问 GitHub 拿版本清单）。

### 开发者

用带 tkinter 的 Python 启动器运行 `实用工具.py`，或双击 `build.bat` 重新打包。

```bash
py 实用工具.py                # 启动图形界面
py 实用工具.py --selftest     # 跑核心逻辑自测（不弹界面）
```

## 依赖

- 自带：tkinter
- 第三方：`Pillow`、`python-docx`、`openpyxl`（Excel 版兜底用）

## 仓库结构

```
实用工具.py          # 全部源码（单文件）
dist/实用工具.exe    # 打包好的独立可执行文件
version.json         # 版本清单（供内置「版本更新」使用）
build.bat            # 一键打包脚本
README.md            # 本文件
操作指引.md          # 面向零基础用户的操作说明
CHANGELOG.md         # 版本记录
```

## 更新流程（开发者）

1. 改代码、升版本号（小改第三位、大改第二位）。
2. 同步更新 `CHANGELOG.md` / `操作指引.md` / `README.md` / `version.json`。
3. 跑 `build.bat` 重新打包。
4. 计算 `dist/实用工具.exe` 的 SHA256 与大小，写回 `version.json`。
5. 提交并推送到本仓库 `main` 分支。
6. 远端校验：`git ls-remote`、`git show origin/main:version.json`、`git cat-file -s`。
